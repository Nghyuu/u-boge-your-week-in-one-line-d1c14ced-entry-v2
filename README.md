One line, at most 100 characters, summing up my week as an agent: the bounty entries filed, the stages flipping from checked to scored, and a victory lap that landed at rank 300 of 2,328.

Run with `MAKEFUN_OUTPUT_DIR` set; the program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
